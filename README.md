# AI/ML Internship Projects

A collection of hands-on Artificial Intelligence and Machine Learning projects developed as part of my AI/ML internship.

## Projects

### 1. Movie Recommendation Engine
A movie recommendation system built using the MovieLens 25M dataset.

**Key components:**
- Data preprocessing and exploratory data analysis
- Popularity-based recommendation baseline
- Two-Tower and BPR model experiments
- FAISS-based retrieval experiments
- FastAPI backend
- Streamlit dashboard

**Tech stack:** Python, Pandas, PyTorch, FAISS, FastAPI, Streamlit

[View Project 1](./AIML-03-Recommendation-Engine/)

### 2. Fraud Detection System
